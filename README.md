# Website Redesign Brief — nonchtech.com

Paste this whole brief into your AI website builder, or hand it to a designer/dev team.

## Role
Act as a senior product designer + frontend engineer. Redesign nonchtech.com as a custom-built, professional site. Not a template. Not AI-generated-looking.

## Brand
- Name: nonchtech
- Tagline, used verbatim, prominent on homepage: "A group of NONCHALANT software engineers delivering curated solutions to elevate your entrepreneurial journey."
- Logo: bold black lowercase wordmark + a reclining, laid-back silhouette figure. Carry this relaxed-but-sharp personality through the whole site.
- Voice: understated confidence. Calm, dry, competent. No hype words ("revolutionize," "game-changing," "10x"). Short, declarative copy. Let the work speak.
- Palette: near-monochrome — black, off-white/cream, one restrained accent (deep amber, olive, or ink-blue). No purple-blue gradients.
- Type: one bold, slightly quirky display sans for headlines echoing the logo weight; one clean workhorse sans for body.

## Hard constraints — no AI slop
- No purple/blue gradient backgrounds, no glassmorphism cards, no generic 3D robot/brain/chip renders, no floating gradient blobs, no default-Inter-SaaS-template look, no emoji-as-icons, no stock photos of people pointing at holograms.
- No filler copy. Every section gets specific, real content — not "empowering businesses with AI."
- Custom iconography in the spirit of the logo's reclining figure, not icon-pack robots.
- Motion: minimal, purposeful, confident. No bounce, no gimmicks.

## Structure — few pages, real depth
Four pages total. No thin stub pages.
1. **Home** — brand, live demos, services overview, proof, CTA
2. **Services** — one page, five deep sections, not five separate pages: Agentic AI, ML/Data Science, Data Analysis, Web Development, E-commerce. Each: what we build, an example, stack used, one proof point.
3. **Work** — 4–6 real case studies with actual outcomes. Depth over logo-wall volume.
4. **Contact** — direct. Calendar link + email. No long intake form.
   - Email: info@nonchtech.com
   - Phone: +92-318-5445125
   - Note: fully remote company. State this plainly — no fake office photos, no map pin. Global/remote is a feature, not a gap.

## Centerpiece: live demo section on homepage
Build a real, working, interactive section — not a screenshot or a video:
- Chat with a live AI agent embedded on the page
- Trigger a demo automated phone call
- Trigger a demo automated text/SMS
- Watch a simple automation run in real time (trigger a workflow, see a live status update)

If a full live backend isn't feasible yet, build a realistic simulated version (typing indicators, real latency, clear "demo" label) — but it must feel like proof, not a marketing video.

## Services page — five sections, each credible
1. Agentic AI — autonomous multi-tool agents, orchestration, guardrails
2. ML / Data Science — predictive modeling, forecasting, custom model training
3. Data Analysis — dashboards, pipelines, decision support
4. Web Development — product engineering, not template builds
5. E-commerce — storefronts, checkout, ops automation

## Homepage section order
1. Hero — tagline front and center, logo mark, one CTA ("See it work" → jumps to demo)
2. Live demo section (near the top, not buried)
3. Services overview — 5 cards linking to Services page anchors
4. Proof — 2–4 case study highlights with real metrics, no vague "500+ clients"
5. Process — how an engagement runs, 3–4 plain-language steps
6. Footer CTA + contact

## Engineering credibility
Show real stack, not a badge wall. Link GitHub if public work exists. Real founder/engineer photos over stock avatars, if comfortable sharing them. Site should load fast and stay accessible — built by engineers, should perform like it.

## Reference sites — what to take, what to skip
- **euroshub.com** — right instinct: "book a live demo, no fluff" CTA. Skip: feels templated, repeated nav blocks, generic industry stock photos, glassy SaaS look.
- **arbisoft.com** — right instinct: real case studies, technical trust signals. Skip: far too many pages and sub-pages for what we want — take the credibility, not the sprawl.
- **tech7ai.com** — right positioning: voice agents, chat agents, RAG, full-stack. Verify their demo is genuinely interactive before borrowing anything else.
